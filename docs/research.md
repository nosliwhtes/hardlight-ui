# Research evidence map

Research/inspection date: **2026-10-20, America/Chicago** (some retrieval timestamps are 2026-10-21 UTC). This is an evidence map for original design recommendations, not a trend ranking, usability study or comparative benchmark. The atlas's `kind` is a coarse source category: APG and web.dev are guidance, not normative WCAG requirements merely because their category is `standard`.

Method: primary standards/system reading, current gallery extraction, publisher project accounts, and bounded live Chrome wide/narrow captures of selected actual sites. The release coordinator inspected the private reference contact sheets; the atlas author also inspected those sheets and the structured observations. Only initial sampled views and DOM/overflow observations were available for most sites; no end-to-end task study was conducted. Third-party screenshots and branded assets are research-only, not distributed examples.

## Accessibility, interaction and implementation evidence

| Source ID and URL | Evidence and decision it changes | Boundary |
| --- | --- | --- |
| `wcag22` — [WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Normative requirements inform text/non-text contrast, reflow, labels, input paths and focus. AA 2.5.8 target size is 24×24 CSS px with specified exceptions; AA 2.4.11 says focus is not **entirely** obscured. | A design can adopt more generous touch targets or full focus visibility without misreporting them as the AA minimum. Partial tools do not establish conformance. |
| `apg-disclosure` — [WAI APG disclosure navigation](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/) | Illustrative primary interaction guidance: ordinary site links do not require ARIA `menu`; disclosure buttons expose expanded state, Tab reaches links and Escape closes/returns focus. | APG warns about browser/AT support and production use. Optional arrows supplement Tab; do not copy the example and assume tested support. |
| `material-rail` — [Material 3 navigation rail](https://m3.material.io/components/navigation-rail/overview) | Platform design-system guidance for primary destinations on suitable layouts; prompts an explicit wide/narrow navigation decision. | Version/platform-sensitive, not a universal destination count or breakpoint law. |
| `fluent-layout` — [Fluent 2 layout](https://fluent2.microsoft.design/layout) | Primary guidance on structural layout, spacing, responsive grouping and alignment; informs stable task chrome and density decisions. | A system-specific model, not permission to transplant Microsoft identity or impose its layout everywhere. |
| `carbon-table` — [Carbon data table](https://www.carbondesignsystem.com/building-blocks/core/components/data-table) | Primary component guidance separates table toolbar, sort, selection, expansion and batch actions; gives data comparison room rather than nesting tables into small cards. | Not a spreadsheet replacement or a rule that all data must be tabular; interaction complexity still needs product testing. |
| `govuk-tasks` — [GOV.UK task list](https://design-system.service.gov.uk/components/task-list/) | Use for long complex services where people need order choice and multiple sessions; distinguish from a required sequence and from an answer summary. | The source explicitly says to simplify first and not use this pattern for tasks that must happen in a fixed order. |
| `govuk-errors` — [GOV.UK error summary](https://design-system.service.gov.uk/components/error-summary/) | A linked summary plus consistent field messages supplies a navigable correction path; informs the form/recovery state ledger. | Does not imply every small inline interaction needs a page-level summary. |
| `govuk-service` — [GOV.UK service navigation](https://design-system.service.gov.uk/components/service-navigation/) | Primary guidance plus wide/narrow browser observation: service identity/current item are separate from content and local actions. | Cookie message was visible in the capture; the embedded component example is not a completed live service task. |
| `web-vitals` — [web.dev Web Vitals](https://web.dev/articles/vitals) | Technical guidance keeps field performance at the 75th percentile separate from laboratory diagnostics; motivates image/effect budgets and honest fallback. | One local run, a screenshot or a gallery award is not field Core Web Vitals evidence. |

## Gaps and safeguards

- [Lando Norris](https://landonorris.com/) returned semantic body content, but the sampled visual state was a neon preloader. [Lusion](https://lusion.co/) returned 200 and content/menu in the DOM, but the screenshot still showed a 100% preloader after four seconds. Neither is evidence of completed navigation, landing composition or motion quality; neither is an atlas recommendation source.
- [Format by Obys](https://format.obys.agency/) timed out after 30 seconds. Record a gap, not a visual review.
- An attempted Stripe accessibility-article URL resolved to “Page not found”; it is not a supporting source. The real Stripe homepage and primary standards are used instead.
- The sampled wide/narrow actual sites in the coordinator's captures showed no horizontal overflow at those sizes. That is a bounded implementation observation, not certification of reflow, keyboard usability, accessibility or task completion.
- No authenticated product flows, conversion experiments, audience comprehension tests, full assistive-technology matrix or field-performance study were conducted. Current content/redirects can change; reread and re-inspect sources before a consequential reuse.

## What is original here

All sixteen atlas grammars, their names/subtitles, compositional proposals, palette seeds, interaction/mobile adaptations and failure conditions are authored recommendations. Source IDs indicate evidence or inspiration, not endorsement by the source or instructions to reproduce its site. The workflow deliberately combines subject-specific art direction with routes, states and browser proof. Validation tests check schema, identifiers and shipped reference integrity; they do not manufacture taste scores or claim empirical superiority over Impeccable or any other tool.
