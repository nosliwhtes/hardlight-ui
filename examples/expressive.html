4 works in running order.
18:30Iris ValeLight / 20 min+

A room remembers blue

A slow sequence of colored planes crosses an empty wall. Each new field changes the one you remember. The work is an imagined study in the distance between seeing and naming.

Sensory note: gradual color changes; no flashing. Seating is part of this imagined installation.

19:00Low AssemblySound / 30 min+

Intervals for an empty hall

Two tones begin far apart and approach without meeting. Between them, the building becomes an instrument. An imagined listening work for patient ears.

Sensory note: sustained low frequencies and a darkened room. This fictional program proposes a quiet exit and return route.

19:45The Fold PracticePerformance / 25 min+

Instructions for a shadow

One performer, a sheet of paper, a fixed light. The smallest fold changes the scale of the room. The audience sees the making and the image at the same time.

Sensory note: low steady light, no audience participation. A written description accompanies this imagined work.

20:30Morrow UnitLight / 30 min+

What remains when we leave

A projected circle is slowly interrupted by the traces of earlier images. The final composition is neither a record nor a clean slate, but the evening folded into one frame.

Sensory note: slow projected motion and a darkened room; no rapid flashing.

Access as a starting point

The imagined venue has a step-free entrance, seating in each installation and a quiet room. In a real event these details would require venue verification, not a decorative accessibility badge.

Doors in this fictional program open at 18:00. Works run in the order shown; visitors could leave between works. These are design assumptions, not travel instructions.

About the study

Not a spectacle.
A different kind
of attention.

Afterimage is an invented gathering built around a simple idea: an artwork does not end at the edge of its frame. It continues in the room, in the next work, and in what a visitor takes away.

This page explores how a loud graphic identity can coexist with plain navigation, a readable program and honest practical information. The optical print, copy and code are original.
